### SQl Training

- What is SQL ?
    SQL - Structured Query Language

- What is used for ?
    - CREATE Database
    - Store Data
    - Read Data
    - Update Data
    - Delete Data

- What is a DATABASE ? is a container that has tables, rows and columns

- Types of Databases
    - SQL Database - Relational Database
        - Structured 
        - Uses Tables
        - Uses rows and columns
        - Has relationships (liniking tables together)

    - Database Concepts
    ======================
    -   Table
    -   Row (Records)
    -   Column (Field)   
    -   Primary key  
    -   Data Types 
        - INT (integer) - stores whole numbers (1,2,3,90,600)
        - VARCHAR(255) (Variable Character) - email, name, titles
        - TEXT - Store long text (Product descriptions, Blog content, Comments, etc)
        - BOOLEAN - true/false and also when we need to store 1/0 (is_admin: 1/0, is_active: 1/0
        - DATE - Store data e.g 2026-02-18 - Birth date, Order Date
        - DATETIME - stores date + time (created_at, updated_at, login_time, etc) 
        - TIMESTAMP: like DATETIME but this auto-updates
        - DECIMAL - Store exact decimal numbers DECIMAL(10,2) -  10 total digits, 2 digits after decimal (DP)
        - CHAR - Fixed length string - Store Gender (M, F)

        ## Examples
        - MySQL
        - PostgreSQL
        - Microsoft SQL Server
        - SQLite
        - Oracle 

    - NoSQL Database
        - Flexible 
        - Document-based
        - JSON-like
